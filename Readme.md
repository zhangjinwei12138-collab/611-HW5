# BIOS611 – Clustering Homework

This repository contains my solutions for **Task 1** and **Task 2** of the BIOS611 Clustering assignment.

## Contents
- `clustering.R`: code to run both tasks (Task 1: K-means + Gap Statistic, Task 2: Spectral Clustering).
- `clustering_report.pdf`: final report including figures, methods, and interpretation.
- `figs/`: figures for both tasks.
  - `task1_gap_vs_side_length.png`
  - `task2_gap_vs_maxradius.png`
- `artifacts/`: intermediate CSV results.
  - `task1_gap_results.csv`
  - `task2_spectral_gap_results.csv`
